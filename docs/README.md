# Documentation — Smart Campus Parking System

## Module Description
Project documentation including hardware wiring diagrams, pin assignments, meeting notes, and design decisions.

## Owner / Responsible Member
**All team members** — everyone is responsible for keeping documentation up to date.

## Directory Structure
```
docs/
├── wiring-diagrams/    # Hardware connection diagrams (PDF, PNG, Fritzing files)
└── meeting-notes/      # Weekly meeting notes (Markdown files, named YYYY-MM-DD.md)
```

## Setup Instructions

### Adding a Wiring Diagram
- Export from Fritzing, KiCad, or draw.io as PDF and PNG.
- Name the file descriptively: e.g., `sensor-module-wiring-v1.pdf`.
- Place it in `docs/wiring-diagrams/`.

### Adding Meeting Notes
- Create a new Markdown file in `docs/meeting-notes/` named with the date: e.g., `2025-09-15.md`.
- Use the template below.

#### Meeting Notes Template
```markdown
# Meeting — YYYY-MM-DD

**Attendees:** [list names]
**Facilitator:** [name]

## Agenda
1. ...

## Decisions
- ...

## Action Items
| Task | Owner | Due |
|------|-------|-----|
| ...  | ...   | ... |

## Next Meeting
Date: ...
```
